Getting started

What do I need to use Mealie Mobile?

A Mealie server running v2.0 or later that your iPhone or iPad can reach, and a Mealie account on it. The app is a client for your server; it doesn't host recipes itself. It requires iOS 26 or iPadOS 26.

How do I sign in?

Enter your server's address, then either:

  • Username and password: used once to create an API token named "Mealie Mobile". The token is kept in the Keychain and your password is never stored.
  • API token: in Mealie, go to Profile → API Tokens, create one, and paste it in.

If your server uses single sign-on (OIDC) only, use the API token option.

My server doesn't use HTTPS. Will it work?

Yes. Start the address with http://, for example http://192.168.1.20:9000. If you leave the scheme off, the app tries https:// first. Servers on your LAN or a tailnet such as Tailscale work fine. Allow local network access when iOS asks.

The app says it can't connect.
  • Open the same address in Safari on the device. If it doesn't load there, the problem is the network or server, not the app.
  • Check the scheme and port: http:// vs https://, and :9000 or whatever your server listens on.
  • For a home server, make sure the device is on the same network or VPN, and that Local Network access is on in Settings → Privacy & Security → Local Network.

Reminders sync

How do I turn on Reminders sync?

In the Groceries tab, tap Sync with Reminders (or go to Settings → Reminders Sync). Pick an existing Reminders list or let the app create one, and allow Reminders access.

How do I get my items sorted into aisles in Reminders?

Make the list a Groceries list in Reminders: open the list, tap ⋯ → Show List Info → List Type → Groceries. Apple doesn't let apps set the list type, so this is a one-time manual step.

How often does it sync?

When the app opens, every 45 seconds while it's open, within a couple of seconds of any change in Reminders (Siri, Apple Watch, other devices), and right after edits in the app. While the app is closed, iOS runs Background App Refresh when it chooses, typically every 15 minutes or more. Mealie has no push notifications, so changes made in Mealie's web app show up at the next sync.

Sync paused and asked me about deleted items.

That's the safety brake. If many items disappear from one side at once, for example after an iCloud reset, the app stops and asks whether to delete them on the other side too or to restore them. Choose restore if you didn't mean to remove them.

I added "Milk" twice and now there's one "2 Milk".

That's Mealie merging duplicate items on the shopping list. The app folds the duplicate reminder into the existing one so the two lists keep matching.

Recipes & groceries

On Hand isn't working for some ingredients.

On Hand uses Mealie's per-household food flag, so it only applies to ingredients linked to a Mealie food. Recipes imported from the web often have unlinked ingredients. Open the recipe, tap edit, and use Parse Ingredients to link them.

Importing from a photo or text fails.

Photo and text import use Mealie's AI import, which needs an AI provider set up on your Mealie server by its administrator. Importing from a web link works without one.

How do I save a recipe from Safari?

On the recipe's web page, tap Share and choose Save to Mealie. If you don't see it, scroll to the end of the app row, tap More, and turn it on. You need to have signed in to the app once first.

What can I ask Siri?

"Add to groceries in Mealie" and "Sync groceries in Mealie". Both are also available as actions in the Shortcuts app.
